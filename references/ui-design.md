# 会话库 UI 设计规范

## 主流程

搜索会话 → 阅读历史 → 在 Codex 打开，或直接归档／备份／删除。

- 单页双栏。左侧搜索与会话列表，右侧聊天记录。
- 状态筛选保留全部、未归档、已归档、建议整理。补充项目与闲置时间下拉，排序提供最近、最早、体积。
- 顶部提供独立回收站入口。回收站用轻量 dialog 显示删除日期／剩余天数、恢复、明确标注的永久删除及全选删除；与手动备份分开，保持无二次确认。
- 顶部区分真实本机会话和虚构演示。备份通过轻量 dialog 查看、下载和恢复，不增加主页面。
- 列表每页 50 条，显示本页条目范围／总数；底部固定提供上一页、页码跳转、下一页。翻页保留勾选，筛选或排序变化回到第一页。
- 建议在列表中以文字标记，详情展示一两句理由。“建议整理”提供全部／未归档／已归档的独立单选筛选。勾选建议会话后显示“按建议处理”及归档／删除数量，按每条建议直接执行。
- 按钮直接执行，无确认单、二次弹窗、随机口令或关闭 Codex 的流程。
- 删除前校验恢复副本；确认删除成功后进入回收站保留 30 天，单次删除通知提供撤销入口。错误和未验证状态不得冒充成功。
- 旧版冷存档和隔离包允许看见，但保持只读兼容。

## 视觉

- 设置提供 B 暖白阅读（默认）、A 浅色极简、C 深色工作台三套主题；切换即时生效并记住本浏览器选择。无保存或无效值时使用 B，不跟随系统自动更换。主题切换保留搜索、分页、勾选及正在执行的任务。
- 默认采用已确认的方案 B：暖白阅读画布（#faf8f5）、米色列表（#f5f2eb）、墨绿主按钮（#2d5a43）及低饱和陶土建议提示。顶部 52px，左侧约 380px。
- 不显示生命周期图表、健康分数、流程图、大段安全说明或装饰性指标。
- 使用本机系统字体 / PingFang SC，不依赖远程字体、图标或 CDN。聊天正文 15px、1.8 行高，阅读版心最大 860px。
- 列表为白色卡片，显示标题、日期、项目、体积和状态；当前项用墨绿侧线标识，多选项用浅绿底色。搜索及筛选固定在列表顶部，列表独立滚动，分页固定底部。
- 消息采用独立卡片，用户消息使用暖白底和米色侧线，Codex 回复使用白底和墨绿侧线；图片与正文在同张卡片中。代码为深色块，表格与长代码仅在内容容器内滚动。
- 6–8px 控件圆角，细暖色边框，4/8px 间距节奏。红色只用于删除。
- 聊天正文使用安全 Markdown 排版，明确区分标题、列表、引用、代码与表格；表格和代码仅在容器内横向滚动。原始 HTML 显示为文字，远程图片不自动加载，已验证的本地／内嵌图片以附件缩略图展示，点击查看原图；找不到图片时显示文字占位。
- 默认从真实聊天开始，不将自动注入的插件清单、AGENTS.md、环境信息与 Skill 正文当作用户消息；过滤发生在分页与搜索前。用户请求中引用的标签、代码示例保持可读。
- 历史搜索词高亮通过 DOM 文本节点和 mark 实现。

## 交互与可访问性

- 输入即时筛选标题与项目，Enter 才搜索正文；显示真实搜索状态。
- 批量动作使用阅读区底部浮动工具栏，不挤占左侧列表；手机上保持分页可见，预留滚动空间防止遮挡条目。
- 每行独立复选框，不嵌入打开按钮。支持选择本页、全选筛选结果（包含其他页）与清空；标明本页、其他页及筛选外已选数量。
- 批量动作直接执行；弹窗与列表区域显示按已处理条数计算的真实进度条，包含百分比和当前会话；完成后保留 100% 与逐项结果。进度和逐项结果可随时打开，关闭结果不停止后台任务；刷新页面可恢复当前服务内的批量进度。
- 列表每页 50 条，聊天每批 20 条；没有结果、加载中和出错均有文字反馈。
- 异步结果必须对应当前关键词和会话，防止旧请求覆盖当前详情。
- 提供键盘焦点、跳过列表、输入标签、状态通知、Ctrl/Cmd+K 聚焦搜索。
- 700px 以下采用列表／阅读切换，提供返回按钮，Escape 返回列表。
- 验证 375px、760px、1180px 与宽屏，无页面横向溢出。
- 所有动效遵循 prefers-reduced-motion。
- 中英文使用同一布局和操作逻辑，不维护第二套页面。

## 备份位置与取消

- 首页顶部提供“设置”入口，直接查看和修改手动备份保存位置，并说明文件命名；移动端保留有文字标签的可访问齿轮按钮。
- 首次手动备份先收集保存文件夹，用户取消选位置时不创建任务；后续直接使用已选目录。备份记录支持更改并标明旧文件保留原处。
- 单条及批量备份显示实际目录、当前文件读取进度和取消按钮；关闭与取消明确区分。关闭后列表仍可取消，Escape 在备份进度内请求取消。取消完成后区分已完成和已取消，未完成文件不显示为可用备份。
