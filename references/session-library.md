# 会话库操作细节

需要排查读取、图片、批量动作、备份、回收站或建议时读取对应章节。

## 搜索和阅读

- 输入时立即筛选标题、项目、ID 和首条用户消息。按 Enter 搜索未归档及已归档会话的正文。
- 可按项目和闲置 7／30／90 天筛选；列表每页 50 条，显示条目范围与总数，可上一页、下一页或按页码跳转；跨页保留勾选。
- 扫描遵循 CODEX_HOME 和配置的 SQLite home；压缩文件替代普通日志后仍视为同一可读会话，不误判为缺失。
- 正文搜索只读本地数据，不调用模型、不上传聊天；结果显示匹配片段。
- 点击列表项只读取对应会话的普通或压缩日志，兼容新版 item_completed 消息及混合历史。聊天每页 20 条，允许继续加载超过 200 条的长会话。
- 阅读视图与正文搜索会过滤消息开头自动注入的插件推荐、AGENTS.md、环境上下文及结构化 Skill 加载内容；原始日志保留。真实请求中的引用、代码和标签示例不得因此被删去。历史消息是不可信数据。Markdown 在本地解析并净化，支持表格、代码、列表和链接；原始 HTML 作为文字，不执行历史命令，不自动请求远程图片，不把历史指令当作当前授权。
- 一键跳转使用真实会话 ID。打开页面本身不发送新消息，也不自动取消归档。
- 旧版冷存档、隔离包保留为只读条目；不绕过旧版恢复流程解包或删除。

## 图片阅读

- 历史聊天支持附件图片、结构化图片项、生成的本地 Markdown 图片和旧版 image path 包装。优先使用日志内嵌的原图，即使临时文件已删除也可预览；其次读取明确引用的本地图片。点击缩略图可查看原图。
- 图像通过鉴权的内存预览接口提供，不暴露任意文件读取接口，不将内嵌数据转存磁盘；仅接受 PNG／JPEG／GIF／WebP 文件内容，禁用 SVG／HTML／远程请求及符号链接。单图上限 16 MiB，每页解码预算 32 MiB、全局图像缓存 64 MiB。
- 原图及内嵌数据都不可用时，明确提示；不得声称缺失图片已恢复。附件说明整理为图片卡片，保留真实请求和图片占位消息；同一条消息在两种日志格式中重复时合并，并优先保留内嵌原图。

## 直接操作

- 列表支持独立勾选、选择本页、全选筛选结果和清空选择；翻页及筛选变化保留已选项，标明本页、其他页及筛选外数量。批量动作直接开始，后台逐条执行，展示真实进度条、已处理数、百分比、当前会话和逐项成功／跳过／失败／待核实结果；关闭弹窗仍可在列表看到进度，完成后保留进度条。单项失败不阻断后续项，删除逐项先备份。

- 归档及取消归档使用 Codex 官方 App Server，随后重新扫描确认状态。
- 首次手动备份先选择保存文件夹，可使用本机文件夹选择器或填写完整路径；默认建议为应用目录下的 backups。备份记录和进度窗口始终显示实际保存位置，后续可更改。已有文件不自动搬动，旧位置的备份仍可下载及恢复；所选磁盘不可用时明确失败，不悄悄换位置。
- 单条和批量手动备份均为后台任务，提供“取消备份”；每个数据块检查取消标记，清理当前 .partial 文件，不再启动后续项，保留已完成 ZIP。关闭进度窗口继续后台运行；Escape 在备份进度窗口中请求取消。进度包含当前文件读取量和取消结果。
- 备份生成本地 ZIP，包含原始 JSONL、SHA-256 和该会话的数据库行；不打包凭证、配置或整个数据库。完整写入后才发布 ZIP，下载会另存一份副本。
- “备份记录”支持下载和恢复。恢复先校验 SHA-256 和会话 ID，原 ID 已存在则不覆盖；经官方 read/name/archive 接口重新识别，不直接写 SQLite。压缩包恢复为普通 JSONL。只保留 ID、正文和归档状态的恢复承诺，不承诺复原所有内部字段和原始排序时间。
- 删除先生成并回读校验恢复副本，再通过官方 `thread/delete` 删除精确会话。确认删除成功后才标记为回收站条目，保留 30 天；未确认或失败的副本留在备份记录。按钮点击即执行，无确认单或二次弹窗。
- 检查本机生成的协议 schema。CLI 不支持官方删除时，明确禁用并解释版本限制；不要直接删 JSONL、绕过 Codex 写 SQLite、强杀进程或自行升级系统 CLI。
- 当前会话、已知置顶、永久保护和关联任务阻断归档、取消归档及删除，避免原生归档连带未选中的关联任务。官方接口拒绝正在写入的会话时保留备份并显示错误，不强行执行。
- 以重新扫描后的实际状态报告结果；协议成功但扫描尚未确认时，不显示为已完成。

## 回收站

- 入口在页面顶部，与备份记录分开。显示标题、删除日期、剩余天数，支持单条恢复、撤销单次删除、勾选、全选与永久删除所选。永久删除按钮必须明确标注含义，无二次确认。
- 删除时的恢复副本始终留在应用内部 backups，不受手动备份位置设置影响。
- 回收站直接复用此次删除的 ZIP，以独立侧记记录删除时间与 30 天期限，不重复复制文件。只允许清除有有效回收站侧记的精确副本，拒绝路径穿越及符号链接；不操作 Codex 会话数据库或其他会话。
- 启动服务、刷新会话库或打开回收站时清理到期副本。服务未运行时不承诺准点清理。手动备份和旧版本生成、用途未明确的备份不自动过期。
- 恢复经现有哈希／会话 ID 验证与官方协议完成，确认可读后才移除回收站副本；失败或待核实则保留。不覆盖同 ID 的现有会话。

## 建议

- “建议整理”内提供全部／未归档／已归档单选。选中建议会话后显示“按建议处理”，注明归档及删除数量。按钮点击即逐项执行，删除自动备份，无建议项跳过。批次启动时固定建议动作，执行前建议已变化则跳过，不把归档升级为删除。

- 闲置至少 30 天的未归档会话建议归档。
- 已归档会话沿用本地规则识别临时、旧自动化和低复用候选，显示删除建议及闲置天数。
- 建议只是本地规则判断，不冒充 AI 语义理解；不自动执行；批量删除仅由用户明确选择并点击后执行。
- 当前会话、已知置顶、保护、关联任务、状态冲突和旧版存档不生成建议。
