# 动作安全协议

## 聊天预览门

- 点击详情时只读取当前目录库已解析到的单个日志，不批量加载全部聊天正文。
- 目标必须位于 `sessions/` 或 `archived_sessions/`，是普通文件、不是符号链接，且文件名线程 ID 与所选会话一致。
- 仅展示真实用户消息和 Codex 最终回复；系统提示、开发者规则、自动浏览器上下文、附件清单外壳、工具参数、进度消息和 token 统计不进入页面。
- 标题、摘要、路径和消息正文都经过路径缩写与敏感字段脱敏，并始终用纯文本渲染。
- 本地规则摘要只用于快速判断，不得标成 Codex 语义复核结果。
- 正文搜索可检索真实用户消息、Codex 最终回复和工具产出；工具调用参数、系统提示、开发者规则和进度消息不得作为搜索结果或展示片段。
- 长会话只加载受限首尾预览；冷存档和隔离包不自动解压。

## 准备门

1. 取得当前置顶任务快照。
2. 唯一识别数据库；候选歧义立即停止。
3. 验证线程已普通归档、不是置顶或永久保护。
4. 验证日志为允许目录内的普通文件，不是符号链接。
5. 验证父子关系为零或已形成显式完整闭包。
6. 计算完整 SHA-256、数据库架构指纹和精确字节数。
7. 生成只读 manifest 及独立 SHA-256 文件。

## 执行门

- 页面先生成只读本地操作确认单；置顶或数据库校验未通过时在确认单展示阻塞，不直接尝试准备 manifest。
- 页面以“确认单 → 二次确认弹窗”的两个显式点击代替人工输入固定短语。计划、风险信号或会话状态在确认后发生变化时，原确认单失效。
- manifest 的内部确认短语必须与 manifest 完全一致，并只由已通过二次确认的本地执行单使用；页面不展示也不要求用户抄写它。
- 通过 `session_actions.py` 修改索引或日志前，Codex 桌面应用和持有目标 SQLite/WAL/SHM 的 app-server 必须完全退出。
- Codex 自带删除按钮属于应用内部受控动作，不适用上述退出要求；但在官方删除接口未对当前 Skill 开放并通过验证前，不得用模拟点击、私有端点或运行中直接改 SQLite 冒充官方批量删除。
- 先用 SQLite backup API 创建一致性备份并运行 `integrity_check`。
- 冷存档先复制、刷新、哈希校验；使用 zstd 时必须测试解压。
- 再在事务中删除线程/动态工具/父子边并提交；写入不可修改审计后，最后才逐条删除原日志。
- 成功后删除临时数据库备份；失败时从一致性备份恢复数据库，若原日志已删除则从已校验包恢复，保留原始错误。

## 垃圾焚烧厂

- 只接受用户手动拖入的普通归档会话，写入 `planned_action=permanent_delete`；自动整理可以显示“建议永久删除”分类，但不得自动生成永久删除计划。
- 确认单必须单列焚烧数量与字节数，并逐条警告可能重要的会话：价值/待复核/未知分类、真实写入、附件、超过 3 轮、语义产物或超过 20 MiB。
- 有重要预警时，二次确认弹窗还必须勾选知情确认。当前活跃、置顶、永久保护、状态冲突、未索引、数据库歧义和父子依赖继续硬阻断。
- 执行前临时复制并校验每个日志，创建一致性数据库备份；这两者只用于同一次执行失败回滚，不构成恢复期。
- 成功后逐条清除临时副本、数据库备份和包含会话详情的 manifest，不创建隔离包，不保留标题、正文或原路径。
- 最终审计只保留会话 ID、时间、删除字节数和 `content_retained: false`。禁止递归、通配符、符号链接和宽泛路径删除。
- 一旦原日志与索引已按永久删除意图提交，不得在最终清理异常时虚假声称完整回滚；写入脱敏的清理异常审计。

## 恢复门

- 包 manifest 与内容哈希都必须通过。
- 当前数据库架构必须兼容；线程 ID 不得已存在。
- 先解压到同目录临时普通文件并验证原始 SHA-256。
- 在同一恢复窗口中插入线程、动态工具和父子边。
- 依赖目标不存在时停止。
- 成功后移除生命周期包，避免出现两份原始会话。

## 14 天隔离与清除

- 隔离 manifest 一次只允许一个会话，便于独立恢复和清除。
- `expires_at` 必须在隔离动作成功执行时生成；创建计划或准备 manifest 时不得开始计时。
- 未到 `expires_at` 时 `purge` 必须失败。
- 到期后重新执行准备门中的置顶、保护、依赖检查。
- 第二次确认使用不可恢复提示弹窗；内部 `PURGE-FOREVER THREAD_ID` 只在本地助手中传递，不要求用户输入。
- 清除仅删除包 manifest 明确列出的普通文件；禁止递归、通配符和宽泛目录。
- 最终审计只保留会话 ID、时间、清除字节数和 `content_retained: false`。
