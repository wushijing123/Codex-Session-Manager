# Code of Conduct

This project welcomes people who want to follow the rules, give feedback, and submit improvements.

## Expected behavior

- Be respectful and start from good faith
- Focus discussions on facts, evidence, and concrete improvements
- Protect real session content, tokens, secrets, and local paths
- Provide a minimal reproducible example when reporting problems
- Accept specific feedback in code and documentation review

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks
- Attempts to extract real sessions, identities, or local credentials
- Deliberately presenting unverified capabilities as finished
- Publishing sensitive data in discussions, issues, pull requests, or releases

## Enforcement

Maintainers may delete, hide, or close content that violates this code of conduct and may limit future participation when necessary.

## Reporting

If you believe someone has violated this code of conduct, contact the maintainers through a private maintainer-only channel or open a private issue if the repository supports that workflow.
